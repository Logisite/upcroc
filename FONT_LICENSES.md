# Font licences

Upcroc bundles two fonts. Both are licensed under the SIL Open Font License, Version 1.1.

- Google Sans Flex: see `licenses/GoogleSansFlex-OFL.txt`
- Roboto: see `licenses/Roboto-OFL.txt`
- Manrope: see `licenses/Manrope-OFL.txt`

The system font option uses the font already installed on the device and does not bundle anything.
