Pulse

The other half of the animal. The crocodile is not patient and sudden — it is fast, and the fast part only lasts a second. This style is the strike, not the wait.

It is also the honest description of the software. Most of the runtime is a timer. What the user actually experiences is the spike when a match lands. The mark is built out of that one spike.

Philosophy

A monitoring tool that animates constantly trains you to ignore it. This style admits that: nothing in the identity moves, but everything is shaped as if it were about to. Stillness that has tension in it. Restraint, but with the throttle pinned open.

The four devices. 1. Letterform fused with symbol — the mark is a u, the first letter of the name, whose right stem is cut off at an angle so it reads as a spike. 2. Gradient on one element only — a violet→cyan run along the stroke, the strongest current device in identity work right now. 3. The slant adds direction; a pure u has none. 4. The stroke is deliberately unfinished at the bottom right, so the eye expects the next beat.

Story

The bowlA u with a true semicircular bottom, so it is unambiguously the letterform and not a generic arch.
The spikeThe right stem leaves the bowl on a diagonal instead of vertically. It is the only asymmetry in the mark and it carries all the meaning.
The gradientViolet at the top into cyan at the bottom — cold light on metal, the house style of premium software marks.
The groundNear-black, not navy. Neutral so the gradient has nothing to fight.

Usage rules

Minimum sizeB1/B2 at 48px; below that B4, which goes flat cyan.
The spikeThe diagonal right stem is not a mistake. Straighten it and the mark dies.
GradientOn the stroke only. Never on the icon ground, never on both word halves.
MotionOne beat on landing, then nothing. No loop, no idle animation.
